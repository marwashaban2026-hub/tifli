# عالم طفلي — دليل التطوير والتعديل

هذا الموقع مبني ليكون **سهل التعديل والتوسيع** بدون الحاجة لمعرفة برمجية عميقة.
معظم الإضافات المستقبلية تحتاج فقط تعديل ملف واحد: **`js/site-config.js`**

---

## ✏️ كيف أضيف محتوى جديد؟ (الأكثر شيوعًا)

كل هذه العمليات تتم بتعديل **`js/site-config.js`** فقط — لا حاجة لمس أي ملف HTML.

### 1) إضافة صفحة جديدة لقائمة التنقل
أضف سطرًا واحدًا في مصفوفة `SITE_PAGES`:
```js
{ href: "new-page.html", label: "اسم الصفحة" }
```
سيظهر الرابط تلقائيًا في قائمة التنقل بكل صفحات الموقع دفعة واحدة.
(تحتاج بعدها إنشاء ملف `new-page.html` فعليًا، انسخ بنية أي صفحة موجودة كنقطة بداية).

### 2) إضافة فيديو جديد
أضف عنصرًا في مصفوفة `VIDEOS` بنفس شكل العناصر الموجودة:
```js
{ group: "speech", id: "YOUTUBE_VIDEO_ID", age: "2-4 سنوات", title: "العنوان", desc: "الوصف" }
```
- `group` يحدد أي شبكة سيظهر بها الفيديو: `speech` (نطق), `moral` (تربوي — يحتاج أيضًا `filter`: food/behavior/respect/env), `recycle`, `nutrition-recipe`, `exercise`.
- `id` هو معرّف فيديو يوتيوب فقط (الجزء بعد `v=` في الرابط).

### 3) إضافة مشروع تدوير جديد
أضف عنصرًا في `RECYCLE_PROJECTS`:
```js
{ emoji: "🎨", bg: "#FCE3C9", age: "🌿 3-6 سنوات", title: "العنوان", desc: "الوصف", materials: ["مادة 1", "مادة 2"] }
```

### 4) إضافة وصفة جديدة
أضف عنصرًا في `RECIPES`:
```js
{ time: "5 دقائق فقط", title: "🍓 اسم الوصفة", desc: "خطوات مختصرة" }
```

### 5) إضافة تمرين صباحي جديد
أضف عنصرًا في `EXERCISES`:
```js
{ emoji: "🤸", bg: "#FCE3C9", age: "5+ سنوات", duration: "3 دقائق", title: "العنوان", desc: "الوصف", benefits: ["🌱 نمو عام"] }
```

## 🎨 تعديل الألوان والخطوط
كل الألوان معرّفة في أعلى ملف `css/style.css` داخل `:root { ... }`.
غيّر قيمة اللون هناك مرة واحدة وسيتغير في كل الموقع تلقائيًا (مثال: `--teal`, `--amber`, `--berry`).

## 🌐 تعدد اللغات
مفعّل عبر أداة "Google Website Translator" (سكربت جاهز في كل صفحة).
لتغيير اللغات المتاحة، عدّل `includedLanguages` في وسم `<script>` أسفل كل صفحة (قائمة أكواد اللغات مفصولة بفواصل، مثل `en,fr,es`).
⚠️ يحتاج اتصالًا بالإنترنت وموقعًا مستضافًا فعليًا (لن يعمل عند فتح الملفات محليًا من دون إنترنت).

## 🧩 إضافة صفحة جديدة بالكامل (خطوات كاملة)
1. انسخ أي ملف HTML موجود (مثل `exercises.html`) وأعد تسميته.
2. غيّر `<title>` و meta description والمحتوى الرئيسي داخل `<main>`.
3. أضف الصفحة إلى `SITE_PAGES` في `site-config.js` (تظهر في كل القوائم تلقائيًا).
4. إن أردت شبكة محتوى ديناميكية (فيديوهات/بطاقات)، أضف `<div id="اسم-فريد"></div>` في الصفحة، ثم أضف بيانات مطابقة في `site-config.js`، ثم استدعِ دالة العرض المناسبة (`renderVideoGrid`, `renderRecycleProjects`, إلخ) من `script.js` — أو اطلب من فريق التطوير إضافتها.

## 🛡️ ملاحظات مهمة
- المحتوى الغذائي والرياضي في الموقع إرشادي عام فقط، ولا يغني عن استشارة طبيب مختص.
- عند إضافة فيديوهات يوتيوب جديدة، تأكدوا من أنها من مصدر موثوق ومناسبة للأطفال قبل النشر.
- ملف `site-config.js` هو "مصدر الحقيقة الواحد" — أي تكرار للمحتوى يدويًا داخل ملفات HTML يفقد الموقع مرونته، فحافظوا دائمًا على إضافة المحتوى هناك.
